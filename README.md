# 2025 Seahawks SQL Roster Analysis

I’m a Seahawks fan, and I made this project to practice SQL with stats from nine players I selected. I used a JOIN to connect players to their 2025 stats, calculated scrimmage yards, compared totals by position, and ranked players within each position.

## What I found

Of the players I selected, wide receivers had the most scrimmage yards (2,835). Running backs had the most touchdowns (18).

## Files

- `analysis.sql` — the queries I wrote
- `seahawks_roster_analysis..sqlite3` — the database used for the analysis

This is a sample of nine players, not the full Seahawks roster.
## Data source

I used the [Seattle Seahawks’ 2025 regular-season player stats](https://www.seahawks.com/team/stats/2025/reg) as the reference for this project. I selected nine players and entered their stats into my SQLite database.
